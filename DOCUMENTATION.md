
## App Overview
Hold Please is an AI-driven telephony agent. Users provide a natural language prompt detailing who to call and the objective. The agent autonomously navigates phone trees, securely inputs account numbers when requested, waits on hold, and alerts the user upon detecting a live human agent.

## AI Agent Capabilities
- Natural language prompt ingestion for call objectives.
- Autonomous phone tree navigation.
- Secure storage and input of account numbers.
- Real-time hold detection and user alerting.
